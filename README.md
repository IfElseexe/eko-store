# ÈKÓ — Lagos Streetwear Store

A fashion e-commerce storefront demo built with **React + Vite**. ÈKÓ (Yoruba for Lagos) is a fictional Lagos-born streetwear brand — heavyweight tees, hoodies, cargos and accessories, priced in Naira.

**Live demo:** _(deployed on Vercel)_

## Features
- Product catalog with category filtering (Tees, Hoodies, Bottoms, Accessories)
- Product detail view with size selection
- Cart drawer with quantity controls, persisted in localStorage
- Delivery fee logic (free Lagos delivery over ₦50,000)
- Demo checkout flow
- Fully responsive, custom design system (danfo-yellow / ink palette, hazard-stripe motif)
- All product imagery is hand-drawn inline SVG — zero image assets

## Stack
React 19 · Vite · CSS custom properties · localStorage

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
